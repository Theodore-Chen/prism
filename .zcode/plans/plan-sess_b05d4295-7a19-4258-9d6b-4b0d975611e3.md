# prism 架构重设计：DESIGN.md v2 + R0 重构冲刺

## 目标

解决三个已确诊的结构性问题：① 代码九个任务纯追加、从未重组（cmdq↔eq 双向耦合、teardown 手写三遍、自检嵌在生产 probe 里）；② DESIGN.md 约 1/3 过时且缺整整一章 EQ/事件设计，T10 验收标准按硬件发现大概率达不到；③ 没有类型化命令层，T12/T14/T15 将各产生一大坨字节偏移拼装。

交付物分两步：**先写设计**（DESIGN.md v2 重写 + task.json 重切），**再做行为保持不变的重构冲刺 R0**（5 个子任务），之后 T10-T17 在新架构上实施（本次不做）。

四层架构：L0 硬件访问（iseg/bar0/doorbell）→ L1 传输（cmdq/eq/uar/pages）→ L2 固件（状态机/caps/怪癖档案）→ L3 服务（phy/冒烟/netdev）。依赖严格向下，L3 禁止碰线格式。

## 第一步：DESIGN.md v2（原地重写，git 历史保留 v1）

章节规划（标注来源）：

1. **定位与差异化**（保留 v1 §1/§12，修复 netdev 自相矛盾）：prism 与 mlx5_core 的五个本质区别——怪癖档案层（实验发现的一等公民代码）、显式固件接口状态机、微型类型化 accessors（vs 4 万行 mlx5_ifc）、可观测性优先（tracepoint 为主接口）、devres 现代习惯。LOC 硬预算 ~4500。
2. **分层架构**（新）：四层图 + 文件到层的映射 + 层间依赖规则（如"L1 不得引用 fw 语义"、"eq.c 只能经 cmdq 声明的 API 触碰 slot"）。
3. **核心数据结构**（重写 v1 过时的 §2）：设备结构重组——fw.pages[8192] 改动态分配、新增 caps 缓存、**锁地图**（为 T10 硬中断/T13 定时器/T15 NAPI 预设计并发边界）。
4. **命令引擎**（重写 §3，修正 writeq→`iowrite32be(1<<idx)`）：slot/token/邮箱链机制、**完成后端接口**（poll/事件两种模式一个 API + claim/revoke 协议）、**类型化命令层**（`prism_get/set` 按 byte+bit 偏移的 BE accessor，~300 行封顶 + 每条命令的偏移表）、错误分类学（delivery vs status + 命名 syndrome 登记）。
5. **EQ 与事件设计**（全新章节，此前缺失）：CREATE_EQ 阶梯 + QUERY_EQ 读回为权威（固件实建 1 条目）、owner 奇偶规则、双 doorbell 轮询协议（+0x48 commit/+0x40 arm）、数据先行/owner 后提交模型与长尾延迟、~10% 激活率 + destroy/recreate 恢复、slot 生命周期协议；轮询路径保留为调试/恢复手段（模块参数）；T10 事件模式设计（严格镜像 mlx5_core 官方形态：async EQ notifier → cmd 完成分发）。
6. **固件引导状态机**（重写 §4）：9 步（含 ISSI、HOST_ENDIANNESS、SET_HCA_CAP），真实页数（6/~2299），**每条命令的所需状态门禁表**（把 0x2B69B6 陷阱变成查表），teardown 双形态（完整 vs 仅回收）。
7. **怪癖档案**（新）：`struct prism_fw_profile`——eq 权威尺寸来源、known-good caps 补丁（**字段命名化**：log_max_klm≤18 等，字节不变）、激活率重试参数、耐心窗（2000ms）、ISSI outlen=112；boot 时检测填充，消费者查表不再各自硬编码。
8. **PHY 监控**（v1 §6 原样保留）。
9. **netdev 骨架**（保留 + 修复与文档头部的矛盾）。
10. **可观测性**（扩充 v1 §3 的 tracepoint 定义，修复未定义的辅助函数问题）：tracepoint 目录（cmdq_issue/cmdq_complete/eq_event/sq_xmit/rq_poll）+ 黑匣子记录器标准化。
11. **验证框架**（保留 v1 §7 骨架，修订 P1/P2 延迟目标——按长尾发现重新表述为"排除提交长尾的往返时延"，并说明原因）；验收 18 项表更新。
12. **路线图**（重写 §8）：R0 → T11'(trace，提前) → T10'(事件) → T12 → T13 → T14 → T15 → T16 → T17。理由：事件模式调试必须先有观测手段。
