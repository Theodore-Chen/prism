# 可读性整改：日志瘦身 + 注释节食 + 阅读地图 + 命令布局图（R0.7）

## 目标

让"读者第一眼就看懂"：默认 probe 日志收敛为每步一行的引导剧本；注释只留不变量、考古搬档案；每文件开头有阅读地图，fmt.h 每条命令配 ASCII 布局图，配 READING.md 给出 ~600 行协议脊柱的读法。**行为保持不变（金样跑 selftest=1 路径不受影响），零协议字节改动。**

## 改动清单

### 1. 日志瘦身（fw.c + pci.c + mlx5_prism.h）

- pci.c 的 `static bool selftest` 改为全局 `bool mlx5_prism_selftest`（module_param_named 同名暴露），mlx5_prism.h 加 extern；probe 三处判断换用全局名
- fw.c 三面 caps hexdump 墙（caps[max]/[cur]/[post]）改为仅 selftest 时打印；caps 缓存 memcpy 保持无条件
- 其余日志不动：`still wants N`（怪癖证据）、teardown 计数行（金样锚点）保留
- 效果：默认路径 dmesg 收敛为纯文本剧本；selftest=1 完全不变（金样锚点全保留）

### 2. 注释节食（fw.c / eq.c / cmdq.c）

原则：**不变量留代码、考古进档案（引用 progress.md/DESIGN v2）**。四处：

- fw.c `set_hca_cap` 的 ~15 行考古块 → 6 行（不变量 + 指针 + DESIGN §6.2 引用）
- eq.c 文件头 ~23 行任务叙事 → 阅读地图 + 三条实测不变量（owner 提交跟随非 arm doorbell / arm 只管中断 / ~10% 激活）
- cmdq.c 文件头 ~17 行任务流水账 → 阅读地图 + 三条协议不变量（1KB 对齐邮箱 / wmb 非 smp_wmb 及其原因 / 超时故意泄露）
- 刻意不动：eq_poll 双 doorbell、cmd_exec 超时泄露、mailbox 对齐注释——承重墙

### 3. 命令布局图（mlx5_prism_fmt.h）——新增项

为 fmt.h 的每条命令（manage_pages / query_pages / ISSI / access_reg / create_eq / query_eq / destroy_eq / alloc_uar / dealloc_uar）加 ASCII 布局图注释块：

```
 * manage_pages_in (16 + 8×n bytes):
 *   [0:16]   header (opcode/op_mod by engine)
 *   [8:12]   function_id   (PRISM_OFF_MP_FUNC_ID)
 *   [12:16]  num_entries   (PRISM_OFF_MP_NUM_ENTRIES)
 *   [16+8i]  pas[i]        (PRISM_OFF_MP_PAS)
```

弥补命名常量表"无字段全景"的短板——读者在偏移表旁边直接看到每条命令的整体形状。来源：progress.md 历史归档①的实证表，纯注释零代码。

### 4. 阅读地图（新 READING.md + 各文件头地图）

- 新增 READING.md（~70 行）：①~600 行脊柱读法——pci.c probe(184) → cmdq.c cmd_exec(~180) → fw.c bootstrap(~180) → eq.c eq_poll(~80)；②文件到层映射表；③动手路径——build / insmod selftest=1 / 金样门禁 / perf 一条龙；④知识索引——DESIGN v2、progress.md 归档、eqc 翻案假设、宏魔法专题（÷8/÷32 双坐标系、三世界、量尺结构体与 offsetof/sizeof 不求值语义——近几轮讨论的沉淀）
- 各文件头 5-8 行地图（第 2 项一并落地）

## 验证
